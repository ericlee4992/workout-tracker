# Strength Equipment Catalog Research — Group 3

Scope: Hoist Fitness, Arsenal Strength, PRIME Fitness USA, Atlantis Strength, Rogue Fitness, Impulse Fitness, Legend Fitness, Sorinex, Titan.
Every model name/code below was read off a live product listing, manufacturer collection page, or manufacturer PDF catalog. Nothing here is extrapolated from a numbering pattern. Where I could only confirm a line and not its members, that is stated explicitly.

Legend for equipment type: `sel` = selectorized (pin-loaded), `pl` = plate-loaded, `cable` = cable/functional, `rack` = smith-or-rack/freeweight.

If a user is standing in front of an older Hoist ROC-IT, the sticker may read RS-1xxx. Only RS-1301, RS-1502 and RS-1103 are confirmed here by direct sighting; do NOT auto-generate the rest of the RS-1xxx family.

## Confidence

**Covered well (high confidence — manufacturer's own site or manufacturer PDF):**
- **Legend Fitness** — strongest. SelectEDGE (30 models), LeverEDGE (11), plate-loaded/Pro Series (22), specialty racks (6) all read from Legend's own PDF catalogs plus their HTML product index. Two independent sources agree on model numbers.
- **Hoist Fitness** — all lines read directly off hoistfitness.com collection pages: ROC-IT Selectorized (21), ROC-IT Plate Loaded (13), HD Dual Series (11 stations), Club Line (14), Commercial Freeweights (24), Multi-Jungle (6), MotionCage (10), plus home lines. Only caveat is the RS-1xxx/RS-2xxx generation split.
- **PRIME Fitness USA** — complete collection listings for Plate Loaded (17), Hybrid (25 — count matches PRIME's own "25 different machine options" claim), Evolution (12), Prodigy Racks (10). No SKU codes exist to get wrong.
- **Rogue Fitness** — machines, functional trainers, power racks and benches all from roguefitness.com category pages.

**Moderate confidence (authorized dealer sources carrying manufacturer model numbers):**
- **Arsenal Strength** — ~95 models via IRON COMPANY; Arsenal's own site is a JS app that would not render its catalog. Line names (Reloaded, M-1, Alpha, FORGEX) are corroborated. FORGEX model numbers (8005–8015) come from a single dealer.
- **Impulse Fitness** — IT95 codes confirmed on Impulse's own regional site, but the code→exercise mapping came from a distributor. Seven codes in my table are distributor-only (flagged inline).

**Thin / would not ship without more work:**
- **Atlantis Strength** — atlantisstrength.com blocked me on every attempt (403 then 525). All ~60 models come from two US dealers. The codes look internally consistent and dealer listings quote them verbatim, but I have zero manufacturer corroboration. The selectorized-vs-plate-loaded split for some C-prefix leg machines is my inference from the machine type, not a quoted spec.
- **Sorinex** — rack configurations only. Apex and Dark Horse lines identified but not enumerated.
- **Titan Fitness** — one machine. Essentially not researched.

**Could not verify / deliberately excluded:**
- Arsenal **BRAVO** line — named in one search snippet, absent from Arsenal's own line list. No members enumerated.
- Impulse **IF93 / IF8 Line / IF Line** — lines confirmed to exist, zero members enumerated. Do not generate IF-series codes.
- Impulse **IT9514** — code exists on Impulse's site, product name unknown. Recommend omitting from the app.
- PRIME **Selectorized** as a distinct collection — the URL 404s; the selectorized machines appear to ship as EVOLUTION. "PRIME Strive" leg/squat press seen only at one dealer.
- Rogue **Rotary Hack Squat** and **Reflex Hack Squat** — appear in third-party review blogs, NOT on roguefitness.com. Excluded as unverified.
- Hoist **HF-series** add-on benches (HF-5165, HF-4263-MB, HF-4145-PL) — from a search snippet only, collection page not loaded.
- Atlantis **"Precision Series Plate-Loaded Hack Squat"** listed by a dealer with no model code visible.
- Legend's benches and storage catalogs — not opened.
- Sorinex **Apex** / **Dark Horse** rack configurations — lines confirmed, members not enumerated.

**Recommendation for the app:** ship Legend, Hoist, PRIME and Rogue as-is; ship Arsenal and Impulse with the inline caveats respected; hold Atlantis behind a "verify against the machine's own sticker" prompt or re-research it from a reachable Atlantis source (their ArchiExpo PDF catalog at pdf.archiexpo.com/pdf/atlantis-strength-equipment-79686.html is the obvious next step); re-research Sorinex and Titan before including them.
